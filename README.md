# StatContext

A stats app for casual fans. Every stat explained in plain English with real context — not just numbers, but what those numbers actually mean.

**Live app:** https://stat-context.vercel.app

## Why StatContext?
ESPN and CBS Sports are built for die-hards who already know what every stat means. StatContext shows the same stats but explains them in plain English and tells you where a player ranks — so a casual fan actually understands what they're looking at. Starting with MLB baseball, with more sports coming.

## Tech Stack
- React + Vite
- Tailwind CSS
- MLB Stats API (starting sport - free, no key required)
- Deployed on Vercel

## Running locally
```bash
git clone https://github.com/Bryan-Cabrera/stat-context.git
cd stat-context
npm install
npm run dev
```
